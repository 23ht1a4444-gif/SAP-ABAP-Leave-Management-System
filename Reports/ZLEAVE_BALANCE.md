# ZLEAVE_BALANCE

## Description

`ZLEAVE_BALANCE` is an SAP ABAP report used to display the leave balance details of employees.

The program retrieves leave balance information from the `ZLEV_BALENCE0549` table and displays the results in ALV Grid format.

## Purpose

- Displays employee leave balance details.
- Shows total available leave days.
- Shows used leave days.
- Shows remaining balance days.
- Supports filtering by Employee ID.
- Supports filtering by Leave Type.
- Displays the results in ALV Grid format.
- Allows the user to export the report data to Excel.

## Features

- Employee ID filter
- Leave Type filter
- Total Days
- Used Days
- Balance Days
- ALV Grid display
- Zebra row formatting
- Sorting and filtering using ALV
- Excel export

## Usage

The report is used to view and analyze the available, used, and remaining leave balance of employees.
