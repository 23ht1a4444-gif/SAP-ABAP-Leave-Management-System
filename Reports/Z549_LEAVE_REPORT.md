# Z549_LEAVE_REPORT

## Description

`Z549_LEAVE_REPORT` is an SAP ABAP report used to display employee leave request details.

The program retrieves leave request information from the `ZLEAVE_REQ0549` table and displays the data in ALV format.

## Purpose

- Displays employee leave requests.
- Provides employee-wise leave request information.
- Supports filtering by Employee ID.
- Supports filtering by date range.
- Supports filtering by leave request status.
- Displays the results in ALV Grid format.
- Allows the user to export the report data to Excel.

## Features

- Employee ID filter
- From Date and To Date filters
- Status filter
- ALV Grid display
- Sorting and filtering using ALV
- Excel export

## Usage

The report is used by managers or users to view and analyze submitted employee leave requests based on different selection criteria.
