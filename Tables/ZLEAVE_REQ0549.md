# ZLEAVE_REQ0549

## Description

`ZLEAVE_REQ0549` is the Leave Request table of the SAP ABAP Leave Management System. It stores the leave requests submitted by employees.

The table contains the information required to track an employee's leave request from submission to approval or rejection.

## Purpose

- Stores employee leave request details.
- Maintains leave type and leave duration information.
- Stores the reason for requesting leave.
- Maintains the current status of the leave request.
- Stores approval-related information.
- Supports the Manager Approval program.
- Provides data for the Leave Request Report.

## Usage

This table is used by the Leave Request program to store submitted requests and by the Manager Approval program to process and update their status.

The Leave Request Report reads this table to display and filter employee leave requests.
